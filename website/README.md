# buildfromideas.com

The public website for Buildd From Ideas (BYLD). A static, multi-page site generated by one Python script.
No framework, no npm install, nothing to break.

| Path | What it is |
| --- | --- |
| `content.py` | **All copy and data.** Products, stats, franchise comparison, FAQs, partners. Edit this first. |
| `build.py` | Page templates, product mock-ups, SEO (titles, JSON-LD, sitemap, robots, llms.txt). |
| `static/` | CSS, JS, logos, favicons. `static/root/` files are copied to the site root. |
| `assets/` | Source screenshots (JPEG). The build makes optimised `.jpg` and `.webp` copies. |
| `og.js` | Renders the 1200×630 social share images into `public/og/`. |
| `public/` | **Generated output. Deployed as-is. Don't edit by hand.** |
| `vercel.json` | Clean URLs, redirects, caching and security headers. |

## Build

```bash
python3 build.py
```

```bash
node og.js
```

`build.py` needs Python 3 and Pillow. `og.js` needs Playwright with Chromium; run it when a page title changes.

## Common changes

- **Update a number** (hotels live, revenue managed): `STATS` in `content.py`.
- **Change a product's status** (Pilot → Live): its `status` in `PRODUCTS`.
- **Add a product**: add a dict to `PRODUCTS` (copy an existing one), add its icon to `PICONS` in `build.py`,
  and either a screenshot in `assets/` (`"visual": {"type": "shot", ...}`) or a mock in `MOCKS`.
  It gets its own page, nav entry, sitemap entry and share image automatically.
- **Add a screenshot**: save a JPEG in `assets/`, reference it by file name without extension.

## Deploy (Vercel)

Point a Vercel project at this repository with **Root Directory = `website`**. No build command is needed:
`public/` is committed and served directly. Then add the `buildfromideas.com` domain to the project.

After the first deploy: submit `https://buildfromideas.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Copy rules

- Only claims we can stand behind. Mock-ups are labelled *Illustrative*; real screens say *Live product*.
- Product status must match reality.
- Company name is **Buildd From Ideas** (double d). Short name **BYLD**. The logo is white and always sits on a dark background.
